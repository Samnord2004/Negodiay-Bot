# 📦 Десктопная версия, выбор диска и Cloudflare HTTPS-туннель

Портал команды «Негодяи» полностью подготовлен как **самостоятельное десктопное приложение** для **macOS (Apple Silicon + Intel `.dmg`)** и **Windows (`.exe`)**, со встроенным выбором локального диска хранения и автоматическим внешним **HTTPS-туннелем Cloudflare**.

---

## 1. Сборка универсального установщика `.dmg` для macOS (Apple Silicon + Intel)

Конфигурация `electron-builder.json` настроена на сборку **единого Universal `.dmg` образа**, который работает нативно как на новых Mac с процессорами **Apple Silicon (M1 / M2 / M3 / M4)**, так и на **Intel Mac** (`x64` + `arm64`).

### Вариант А. Сборка на своём Mac (в 1 команду)
В терминале на Mac в папке проекта выполните:
```bash
./build-mac-dmg.sh
```
*(Либо через npm: `npm install && npm run dist:mac`)*

По завершении в папке `dist-electron/` появится готовый образ **`Негодяи-0.0.0-universal.dmg`** (и `.zip`), а Finder откроет папку автоматически.

### Вариант Б. Автоматическая сборка в облаке GitHub Actions
Если под рукой нет Mac, используйте готовый воркфлоу `.github/workflows/desktop-build.yml`:
1. Загрузите изменения на GitHub (`git push`).
2. Откройте **Actions ➔ Desktop Build (.exe and Universal macOS .dmg) ➔ Run workflow**.
3. Выберите платформу (`mac`, `win` или `all`) и пул macOS (`macos-latest`, `macos-14` или `macos-15-intel`).
4. Скачайте готовый `.dmg` или `.exe` из раздела **Artifacts**.

> **Примечание для первого запуска на Mac:** поскольку образ не подписан платным сертификатом Apple Developer ($99/год), при первом открытии на Mac кликните по приложению правой кнопкой мыши ➔ **«Открыть»** (или в *Системные настройки ➔ Конфиденциальность и безопасность ➔ «Всё равно открыть»*).

## 2. Выбор локального диска для хранения данных (фото, видео, документы, БД)

Откройте **Панель Администратора ➔ вкладка «Диск & Хранилище»**:
1. В списке дисков автоматически отобразятся все локальные и внешние накопители (внешние SSD/USB в `/Volumes/...` на Mac, диски `D:\`, `E:\` на Windows) с остатком свободного места.
2. Можно выбрать диск одним кликом, просмотреть папки встроенным навигатором, создать новую папку или (в десктопной версии `.dmg`/`.exe`) нажать **«Обзор в Finder / Проводнике»**.
3. Нажмите **«Применить диск»**:
   - Вся база (`app_storage.json`) и все сохранённые медиафайлы из `media/` (фото, видео, документы) автоматически перенесутся на выбранный диск.
   - Настройка сохраняется в `storage_config.json` (внутри `Application Support/Негодяи` на Mac или `%APPDATA%\Негодяи` на Windows) и запоминается после перезапуска.

## 3. Внешний HTTPS-туннель Cloudflare (для телефона и удалённых ПК)

Прямо внутри **Панель Администратора ➔ вкладка «Диск & Хранилище»** встроен модуль **Cloudflare Tunnel**:

1. **Автоустановка `cloudflared`**: если утилита ещё не установлена на сервере, нажмите кнопку **«Установить cloudflared»** — приложение само скачает официальный модуль под вашу архитектуру (`darwin-arm64`, `darwin-amd64` или `windows-amd64`).
2. **Режим 1 — Быстрый HTTPS-туннель (без регистрации)**:
   - Нажмите **«Запустить HTTPS-туннель»**.
   - Сервер сразу сгенерирует публичный защищённый адрес вида `https://xxxx.trycloudflare.com` и **QR-код** для мгновенного открытия с телефона.
   - Поддерживает HTTPS и WebSocket (`/ws/poker`).
3. **Режим 2 — Свой внешний домен (Cloudflare Tunnel Token)**:
   - Выберите вкладку **«Свой внешний домен (Tunnel Token)»**.
   - Укажите ваш постоянный домен (например, `https://portal.negodyai.ru`) и вставьте токен из панели Cloudflare Zero Trust (*Networks → Tunnels*).
   - Включите галочку **«Автозапуск туннеля при включении сервера / программы»**, чтобы внешний домен поднимался сам при запуске приложения.

### Подключение удалённых участников через `.dmg` / `.exe`:
Участники, установившие десктопное приложение на свои компьютеры, могут открыть в верхнем меню программы:
**«Сервер и Домен» ➔ «Указать внешний домен / Cloudflare туннель...»** — ввести ваш домен (например, `https://portal.negodyai.ru`), после чего приложение подключится к центральной базе вашего локального сервера.
