# 📦 Сборка десктопных приложений (.exe для Windows и .dmg для macOS)

В проект добавлена полная конфигурация для упаковки портала туристической команды «Негодяи» в самостоятельные настольные приложения для **Windows** (`.exe`) и **macOS** (`.dmg`).

---

## 🧭 Как это работает под капотом

Десктопная версия построена на базе **Electron**:
1. При запуске `.exe` или `.dmg` приложение запускает встроенный локальный сервер в фоновом режиме на безопасном свободном порту.
2. Автоматически открывается стильное нативное окно приложения (1360×900) в фирменной пиратской стилистике Негодяев.
3. Все данные (чат, фонд, истории, квесты, участники) сохраняются локально в `data/app_storage.json`, поэтому приложение работает **100% автономно даже без подключения к интернету**.
4. Встроенный сетевой покер и эмулятор Mortal Kombat 3 функционируют точно так же, как в веб-версии.

## 🚀 Способ 1. Автоматическая облачная сборка через GitHub Actions (Рекомендуется)

Вам не нужно устанавливать тяжелые компиляторы и утилиты на свой компьютер. В проект добавлен файл `.github/workflows/desktop-build.yml`.

1. Загрузите проект в ваш GitHub-репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Add desktop build support"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/negodyai-portal.git
   git push -u origin main
   ```
2. Откройте репозиторий на GitHub и перейдите во вкладку **Actions**.
3. Выберите воркфлоу **«Сборка десктопных приложений (.exe и .dmg)»** и нажмите **«Run workflow»**.
4. GitHub выделит два нативных сервера:
   - **Windows Runner** соберет нативный `Negodyai Setup.exe` (инсталлятор NSIS + портативный exe).
   - **macOS Runner** соберет нативный `Negodyai.dmg` (универсальный для процессоров Apple Silicon M1/M2/M3/M4 и Intel).
5. Через 3-5 минут скачайте готовые установочные файлы прямо из раздела **Artifacts** или **Releases**.

## 💻 Способ 2. Локальная сборка на своем компьютере (в 1 команду)

### Для пользователей Windows (сборка `.exe`):
В командной строке или PowerShell в папке проекта выполните:
```cmd
npm install
npm run dist:win
```
По завершении сборки в папке `dist-electron/` появятся:
- `Негодяи Setup 0.0.0.exe` — установщик для Windows (создает ярлыки на рабочем столе и в меню «Пуск»).
- `Негодяи 0.0.0.exe` — Portable-версия (запускается сразу с флешки без установки).

---

### Для пользователей Mac (сборка `.dmg`):
В терминале Mac в папке проекта выполните:
```bash
npm install
npm run dist:mac
```
По завершении сборки в папке `dist-electron/` появится:
- `Негодяи-0.0.0.dmg` — образ диска с фирменным окном установки (перетаскивание иконки в папку «Программы»).
- `Негодяи-0.0.0-mac.zip` — запакованный бандл приложения `.app`.

## 🌐 Альтернатива: Установка как PWA (без сборки инсталляторов)

Портал оптимизирован как прогрессивное веб-приложение (**PWA**):
1. Откройте сайт портала в браузере **Google Chrome**, **Microsoft Edge** или **Safari** (на Mac).
2. В адресной строке нажмите значок **«Установить приложение»** (или в меню браузера: *«Установить Негодяи...»* / *«Добавить в Dock»*).
3. Приложение появится в меню «Пуск» на Windows или в Launchpad/Dock на Mac и будет открываться в отдельном изолированном окне без адресной строки браузера.

## ⚙️ Структура файлов Electron в проекте:

- `electron/main.cjs` — главный процесс десктопного приложения (запуск сервера, создание окна, управление жизненным циклом).
- `electron/preload.cjs` — безопасный контекст моста.
- `electron-builder.json` — конфигурация упаковки (цели NSIS, Portable, DMG, категории, разрешения окон).
- `.github/workflows/desktop-build.yml` — CI/CD воркфлоу сборки на серверах GitHub.
